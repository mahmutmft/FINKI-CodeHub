## 🚀 Getting Started

### Prerequisites
- Git installed on your machine
- Basic understanding of version control

### Installation
1. Clone the repository
```bash
git clone https://github.com/mahmutmft/FINKI-CodeHub.git
```
2. Navigate to the desired course directory
```bash
cd FINKI-CodeHub/<course-name>
```
3. Follow specific instructions in each course directory

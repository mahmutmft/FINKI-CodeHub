# Java Programming Exercises (F23L2W109)

## Overview
This repository contains assignments for the **"Java Programming"** course at the Faculty of Computer Science and Engineering. It covers various data structures, algorithms, and fundamental programming concepts in Java. Each folder corresponds to a specific exercise, with solutions for tasks related to arrays, linked lists, trees, graphs, sorting algorithms, and more.

## Project Structure
The project is organized into the following directory structure under `src/main`:

### `java`
This folder contains my solutions to exercises and tasks from the course. Each file or subfolder represents a specific problem or concept I've worked on.

### `learning`
This folder contains my personal learning materials and examples. Here, I have documented and solved problems to better understand key concepts. The files in this folder are well-documented and serve as a reference for how to solve problems step by step.

### `resources/teacher`
This folder contains code and materials provided by the professors. It includes implementations of data structures and algorithms used as a reference for my solutions. These materials are used as a foundation for my own implementations and learning.

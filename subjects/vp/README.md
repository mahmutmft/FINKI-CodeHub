# Visual Programming (VP)

Centralized links for all Visual Programming labs and materials.

## Labs
- **Lab A (current)** → `../../labs/vp/lab-a`
- **Lab A (legacy)** → `../../labs/vp/lab-a-legacy`

The legacy version preserves the original lab that lived inside `VP/LAB A/`. The `labs/vp/lab-a` directory contains the newer iteration (with the extended features such as book likes). Both remain in the repo so nothing gets lost, but the subject folder now acts as the index instead of duplicating source trees.

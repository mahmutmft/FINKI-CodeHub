# Exercise 01: String Reversal (UDP)

**Protocol:** UDP  
**Port:** 5001

## Description

This server reverses any string sent by the client and sends it back.

## How to Run

```bash
javac Server.java
javac Client.java

# In terminal 1
java Server

# In terminal 2
java Client

```

### Example Protocol

    Client sends: hello world

    Server replies: dlrow olleh

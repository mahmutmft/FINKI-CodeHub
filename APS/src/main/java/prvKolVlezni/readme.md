### Прва задача: Преместување на стрингови

**Опис:**  
Се внесува број на стрингови, се печати низата пред промени, секој стринг што почнува со мала буква се преместува на крајот од листата, и потоа се печати листата.

**Пример:**  
Влез:

4
ova
Eden
Zdravo
hawaii

Излез:

ova -> Eden -> Zdravo -> hawaii

Eden -> Zdravo -> ova -> hawaii


**Објаснување:**
- Стринговите `ova` и `hawaii` почнуваат со мала буква, па се преместуваат на крајот на листата.
- Стринговите `Eden` и `Zdravo` остануваат на своите позиции бидејќи почнуваат со голема буква.
